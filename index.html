Los umbrales precargados son valores de referencia de industria. Sustitúyalos por los umbrales que su Comité de Seguridad haya aprobado formalmente; un indicador sin umbral autorizado no es auditable.

Cómo capturar los datos

Cada indicador necesita dos cifras. Debajo de cada campo se explica exactamente qué debe contar, dónde obtener el dato y cuál es el error más frecuente al calcularlo.

  1. Use la misma fecha de corte para todos los indicadores y anótela arriba.
  2. Capture cifras del periodo completo, no acumuladas del año, salvo que el campo indique otra cosa.
  3. Si no tiene un dato, deje el campo vacío. El indicador aparecerá como «sin datos» en lugar de mostrar una cifra incorrecta.
  4. Conserve la consulta o el reporte del que obtuvo cada cifra: es la evidencia que pedirá el auditor.

Dónde se guardan los datos

La herramienta mantiene una base de datos local dentro del navegador de este equipo. Si además vincula un archivo, cada cambio se escribe en un .json de la carpeta que elija, que puede ser la misma donde guardó este archivo .html: ese archivo es su respaldo y puede copiarse, versionarse o compartirse con el equipo.
